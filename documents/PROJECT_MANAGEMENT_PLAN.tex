Développer un système de gestion des salles pour l'ENSAA en \textbf{6-7 semaines} avec \textbf{2 développeurs} travaillant en parallèle.

\section{Justification de la Répartition}

\subsection{Pourquoi STRATÉGIE 3 ?}

\textbf{✅ Équilibre parfait de la charge :}
\begin{itemize}
    \item Dev1 : 23 jours de développement pur + 6 jours d'aide/tests
    \item Dev2 : 29 jours de développement pur (modules complexes)
    \item \textbf{Résultat :} Charge équilibrée sur 7 semaines (4 modules chacun)
\end{itemize}

\textbf{✅ Modules COMPLETS (backend + frontend) :}
\begin{itemize}
    \item Chaque dev fait ses modules de A à Z
    \item Pas de séparation artificielle backend/frontend
    \item Chaque dev maîtrise complètement ses modules
\end{itemize}

\textbf{✅ Dépendances minimales :}
\begin{itemize}
    \item \textbf{Dev1 :} 100\% indépendant (aucun blocage)
    \item \textbf{Dev2 :} 1 seule dépendance (Filière pour Matière) = 1 semaine d'attente
    \item Après S3, Dev2 est 100\% autonome
\end{itemize}

\textbf{✅ Cohérence fonctionnelle :}
\begin{itemize}
    \item \textbf{Dev1 :} Fondations (Auth, Salle, Filière) + Opération simple (Réclamation)
    \item \textbf{Dev2 :} Gestion avancée (Admin, Matière, Emploi, Réservation)
\end{itemize}

\subsection{Avantages de cette Répartition}

\begin{enumerate}
    \item \textbf{Équité :} 4 modules chacun, charge similaire (23j vs 29j)
    \item \textbf{Parallélisation maximale :} 1 seul point de blocage (1 semaine)
    \item \textbf{Modules complets :} Chaque dev fait backend + frontend
    \item \textbf{Apprentissage complet :} Chaque dev maîtrise toute la stack
    \item \textbf{Flexibilité :} Dev1 termine plus tôt et peut aider Dev2 sur Emploi/Réservation
    \item \textbf{Pas de conflit Git :} Modules différents = fichiers différents
\end{enumerate}

\section{Conclusion}

Ce plan de gestion propose une \textbf{répartition équitable} du travail entre deux développeurs sur \textbf{7 semaines}.

\textbf{Points clés :}
\begin{itemize}
    \item \textbf{STRATÉGIE 3 :} Par Fonctionnalité Métier (4 modules chacun)
    \item \textbf{Équilibre :} Dev1 (23j) vs Dev2 (29j) = charge similaire
    \item \textbf{Parallélisation :} 1 seul point de blocage (1 semaine)
    \item \textbf{Modules complets :} Backend + Frontend pour chaque module

\textbf{Facteurs de succès :}
\begin{itemize}
    \item Communication quotidienne (standup 10 min)
    \item Respect du point de synchronisation (fin S3 : Filière terminée)
    \item Semaine 0 bien maîtrisée (architecture unifiée)
    \item Entraide sur modules complexes (Emploi, Réservation)
    \item Utilisation correcte de Git (branches dev1/dev2, PRs hebdomadaires)
\end{itemize}

\textbf{Durée totale :} 7 semaines (35 jours ouvrés)

\textbf{Livraison :} Système complet et fonctionnel avec documentation
